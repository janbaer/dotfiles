# Copy-ready output

When Jan asks for copy-ready text (cover letters, emails, application answers), put the text in one fenced code block. Nothing else goes inside the block.

Put every comment, caveat, or suggestion above the block, never below it.

## Why

Jan copies the block as-is. Text after the block gets copied too, by accident, if he selects fast. Comments above the block avoid that risk.

## How to apply

- One fenced code block. No text inside it except the copy-ready output.
- All notes, caveats, and suggestions go before the block.
- Nothing after the block.
